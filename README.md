# omnia

Telegram Mini App для генерации режиссёрских сценариев. Бот, API и раздача
страницы запускаются одним процессом на Python.

## Запуск

1. Установите Python 3.11 или новее.
2. Создайте окружение и установите зависимости:

   ```powershell
   py -3.11 -m venv .venv
   .venv\Scripts\Activate.ps1
   pip install -r requirements.txt
   ```

3. Укажите в `.env` публичный HTTPS-адрес сервера в `APP_URL`.
4. Запустите приложение:

   ```powershell
   python bot.py
   ```

Если сеть не открывает `api.telegram.org`, укажите рабочий прокси в `.env`:

```dotenv
TELEGRAM_PROXY=socks5://127.0.0.1:1080
```

Поддерживаются HTTP, SOCKS4 и SOCKS5, в том числе адреса с логином и паролем.

Сервер слушает порт `8080`. Для Telegram нужен публичный HTTPS-домен: направьте
его на этот порт через хостинг или HTTPS-туннель. Тот же адрес укажите в
BotFather в настройках Mini App.

Для проверки интерфейса вне Telegram временно установите
`DEVELOPMENT_MODE=true` и откройте `http://localhost:8080`. Перед публикацией
обязательно верните `DEVELOPMENT_MODE=false`.

## Что уже реализовано

- три бесплатные генерации для нового пользователя;
- атомарное списание лимита и сохранение сценариев в SQLite;
- проверка подписи `Telegram.WebApp.initData` на сервере;
- счёт на 300 Telegram Stars (`XTR`), `pre_checkout_query` и подтверждение оплаты;
- бессрочный Premium после успешного платежа;
- адаптивный интерфейс с генератором, историей и профилем.

Токен хранится только в `.env`, который исключён из Git. Если токен был
опубликован или отправлен третьим лицам, перевыпустите его через BotFather.

## Бесплатное облако

Для Render предусмотрен `render.yaml`. В облаке приложение автоматически
переходит с polling на защищённый Telegram webhook, а адрес Mini App берёт из
`RENDER_EXTERNAL_URL`. Данные хранятся во внешнем PostgreSQL через
`DATABASE_URL`; локальный запуск по-прежнему использует SQLite.

Перед развёртыванием создайте бесплатную базу Neon и передайте её строку
подключения как секрет `DATABASE_URL`. В Render также нужно добавить секрет
`BOT_TOKEN`; остальные параметры Blueprint создаёт автоматически.
